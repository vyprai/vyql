A security scanner that shows its working.

VyQL traces untrusted input through your code to the places where it turns dangerous. Every finding also lists the safeguards it went looking for and didn't find. 

$ curl -fsSL https://dl.vyprsec.ai/vyql/install.sh | sh

macOS and Linux, on amd64 and arm64. There's also Homebrew, a container image, and go install. No account, no API key, and it doesn't phone home.

What a finding looks like

A small Express app that takes a filename from the query string and hands it to the filesystem: 

// app.js
const express = require("express");
const fs = require("fs");
const app = express();

app.get("/download", (req, res) => {
  const name = req.query.name;
  res.send(fs.readFileSync("/var/data/" + name));
});

Scanning it takes no setup, no config file and no choosing which rules to run: 

$ vyql scan .
analysis profile: HTTP API server (api)

2 finding(s):

[P3] [HIGH] VYQL-PATH-001  (conf=high, fp=c61843fd71a2284b)
    source: code.HttpInput @ app.js:6
    sink: code.FilePathAccess @ app.js:7
    taint path: app.jsAttr#80 -> app.jsFormat#81 -> app.jsArg#83
    unless path coveredBy core.PathCanonicalization: not satisfied, no neutralizing
      control dominates the path; none found anywhere on flows
    unless endpoint coveredBy core.PathAccessCheck: not satisfied, no guard on sink

The last two lines are the ones that matter. If a scanner tells you code is vulnerable, it should also tell you what would have made it safe. And when you do have a control in place, it should say why that control didn't count. Without that you are left guessing whether to trust the finding or ignore it.

How it works

Knowledge as data

A small Go engine, plus 12,400 .vyql files you can open and edit. Covering a new framework usually means writing a binding, not patching Go.

One graph, 22 languages

Java, Python and JavaScript are the most complete. Others go from full taint tracking down to simpler coverage, and the scan tells you which you got.

Built for a pipeline

scan exits 1 on anything high or critical, with no setup. SARIF and JSON output. A baseline for codebases that already have findings.

It tells you what it skipped

Files that no frontend could read get reported whether you ask or not. A clean result on a tree nobody parsed looks exactly like a real clean result.
