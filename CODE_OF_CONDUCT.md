# Code of conduct

This project adopts the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its
code of conduct. The canonical text is at that link.

In short: be respectful, assume good faith, and keep technical disagreement
technical. Security work attracts strong opinions about severity and about what
counts as a real finding — argue the evidence.

## Reporting

Report unacceptable behaviour to **conduct@vyprsec.ai**. Reports are handled
privately. The maintainers will review and respond, and will not act on a report
without telling the person who made it what was decided.
