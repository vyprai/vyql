### ecosyste.ms package rankings

`vyql/bindings/packages/top1000.snapshot.json` is generated by
`scripts/fetch-package-top1000.mjs` from the ecosyste.ms packages API
(https://packages.ecosyste.ms). It records package names, registries and
popularity counts — factual data only, no descriptive text.

ecosyste.ms data is published under CC-BY-SA 4.0
(https://creativecommons.org/licenses/by-sa/4.0/). That attribution and
share-alike obligation applies to this snapshot file specifically. The
file is build and test input; it is not loaded at scan time.
